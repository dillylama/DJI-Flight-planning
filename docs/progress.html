What the review found

Every row is fixed in PR 9 and has a test that fails if the fault comes back.

Fault in the 25 Sep plannerWhat it could have done
Demo terrain stayed loaded when a real block was openedA real route planned on made-up ground. At the sample site the plan came out 130–500 m below the true surface, with export enabled.
GLO-30 terrain read half a cell offGround shifted 13 m east and 15 m south under every route.
Gaps in a DEM were skippedA DTM ending inside the corridor put run-in waypoints up to 25 m below ground. A void hiding a ridge showed 100 m clearance on the way home where the truth was a hillside.
Terrain sampled at points, not cell by cellLegs clearing the DEM by 89 m of a planned 100 m. A single-cell peak on an RTH line was missed in 3 positions out of 4.
The file asked for a fully curved pathThe aircraft free to dip below the straight legs that were checked, by 8–28 m in the review's model.
Only the whole job was checked, then sorties were exportedA sortie with legs too steep to fly went out with no warning.
Figure-8s followed the terrainUp to 91 m of height change and legs slowed to 1.5 m/s inside an alignment manoeuvre.
RTH height and Max Altitude were only adviceThe file says "return home" on signal loss and at the end, but cannot carry the height. Nothing made sure it was set.
Input limits were not enforcedAGL 3 m and a zero-width terrain corridor were accepted. A failed calculation could leave the previous plan exportable.
A user DTM's height datum was never askedEvery flight height off by the geoid separation, about 32 m around Prince Albert.
Map distances 0.4 % long north–southSmall, but the new file check caught it. The planner now uses true distances on the ellipsoid.

What "working" means, and the gates to get there

Each gate proves one link in the chain, from a file on the RC to a point cloud from a real job. A gate must pass cleanly before the next. A failure means fix and repeat, not skip.

Done

Safety hardening

  • Every straight leg clears the highest DEM cell touching its corridor by the full AGL. A gap in the DEM stops the plan.
  • Independent file check: each KMZ is built, read back by separate code and checked against the terrain. Only files that pass can be downloaded or published.
  • Clearance budget shown in the planner: AGL − path rounding and lag − your uncertainty allowance (20 m by default). Export refused below 30 m.
  • Straight legs in the file; steep legs and the legs around them slowed so climb and descent stay within 4 and 3 m/s.
  • Export shows the RTH height, Max Altitude and height at waypoint 1 for each sortie, puts them in the file name and asks you to confirm.
  • Proof the tests work: the planner was broken on purpose in 18 ways and the test suite caught all 18.

Still unproven until the hardware says so

What Pilot 2 and the M400 do with the file

  • Does Pilot 2 keep per-waypoint heights, speeds and turn settings when it imports and saves?
  • Does it accept waypoint speeds above 15 m/s? The planner's default line speed is 17 m/s.
  • How does the M400 round a fly-through waypoint on straight legs, and how closely does it hold a steep leg?
  • The waypoint cap, and L3 recording started from a waypoint action.

What no planner can know

  • Obstacles that are not in the DEM: masts, power lines, cranes, turbines, new buildings, taller trees.
  • DEM error beyond the allowance. GLO-30 is about 4 m on open ground and can be 10–20 m on steep or forested slopes; its data is from 2011–2015.
  • The aircraft's own height without RTK: 5–15 m or more.
  • A take-off from somewhere other than the planned home, or a mission started in the air.

Before every flight

  • RTH height at least the value in the file name (…_RTH330_…), with the preset-height RTH mode.
  • Max Altitude at least the value in the file name (…_ALT430).
  • Take off from the planned home point, from the ground. Transit and RTH were checked from there.
  • RTK fixed. Heights in the file are absolute.
  • At waypoint 1 the RC shows the planned height above take-off, within about 10 m. If not, stop the mission.
  • Obstacles that are not in the DEM have been checked for the area.
