# samples/ — RC exports (source of truth for the WPML writer)

Needed: a **Waypoint Route** (not Area Route) exported from DJI Pilot 2 on the RC, with the
**Zenmuse L3** selected and 4 waypoints:

1. WP1: start point-cloud recording
2. WP2: a different speed
3. WP3: plain
4. WP4: stop point-cloud recording

It gives us the M400/L3 enum values, the exact record action XML and the height mode. None of these
are guessed.
